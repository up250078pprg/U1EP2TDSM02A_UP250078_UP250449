## Descripción

Esta práctica tiene como propósito fortalecer el uso de Git y GitHub mediante el desarrollo colaborativo de un proyecto. Los integrantes trabajan sobre ramas independientes, gestionan correctamente la autoría de sus cambios y resuelven conflictos de fusión utilizando las herramientas proporcionadas por Visual Studio Code.

---

## Objetivos

* Crear y administrar ramas de desarrollo.
* Configurar identidades de autor en Git.
* Registrar cambios mediante commits.
* Integrar trabajo colaborativo en una rama principal.
* Resolver conflictos de fusión de manera adecuada.
* Publicar un repositorio en GitHub.
